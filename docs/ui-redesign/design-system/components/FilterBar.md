# FilterBar

The filter bar sits between the page header and a list: search, quick filters, saved views, export.

## Use
- `.mg-search`: a round search field with the icon inside; it filters as you type, instantly.
- Quick filters are `.mg-chip`s; a saved view is a small select.
- Export and other list actions go last as ghost buttons (hidden for roles that may not export).
- Wraps to two lines on a phone; search takes the full first line.
