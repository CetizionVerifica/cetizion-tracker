# RowList

On a phone every list is rows, not a table: who, how much, what and its state.

## Use
- `.mg-rows` in strong glass; each `.mg-row` is a link to the record.
- Two lines: the title and the amount on top; a `muted` meta line and the state badge below.
- Tap targets are the whole row (at least 64px tall). Actions live on the record page or a swipe-free "⋯" sheet, never as tiny buttons in the row.
