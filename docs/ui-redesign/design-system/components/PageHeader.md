# PageHeader

Every page opens with a header: an eyebrow, the title, one line of context, and the glass control bar on the right.

## Use
- `.mg-eyebrow` (12px caps, `text2`): the date on Today, the section elsewhere ("Money").
- Title: `.mg-greeting` (Fraunces 44) on Today only, with the key word in italic `caramel-text` and a drawn underline; `.mg-display` (Fraunces 32) on every other page.
- `.mg-header__sub`: one sentence of what matters now, in plain words.
- `.mg-controlbar`: a glass pill holding the period segmented control, the pause-motion button and the bell with its count. Page actions (a primary button) go in `.mg-header__actions` before it.
