# Sheet

On a phone, dialogs open as bottom sheets; long tasks split into steps.

## Use
- `.mg-sheet`: full width, radius 28 on top, a grab handle, the same head/body/foot as Dialog. Primary buttons are 48px.
- `.mg-steps`: one bar per step; done steps `figure`, the current one `caramel`. The subtitle says "Step 2 of 3" and what the step is.
- Step forms are also used by the Ctrl K palette for actions that need details.
