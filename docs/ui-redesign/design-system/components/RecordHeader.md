# RecordHeader

Every record page (deal, company, PO, project, trip) opens with the same header.

## Use
- Breadcrumbs, then the title (Fraunces 30) with its state badge, then actions on the right: at most one primary, the rest secondary, and "⋯" for the rarely used.
- `.mg-facts`: four to six key facts as label/value pairs (`dt` 11px caps, `dd` 700).
- Below it: tabs for the record's sections, then the content.
